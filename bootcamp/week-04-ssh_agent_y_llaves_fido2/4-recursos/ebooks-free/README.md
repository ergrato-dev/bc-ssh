# Ebooks gratuitos — Semana 04

| Recurso | Descripción |
|---------|-------------|
| [draft-ietf-sshm-ssh-agent — SSH Agent Protocol](https://datatracker.ietf.org/doc/html/draft-ietf-sshm-ssh-agent) | La especificación del protocolo del agente: qué mensajes acepta (añadir, listar, firmar, bloquear) y por qué ninguno devuelve una privada. Nivel avanzado |
| [OpenSSH — PROTOCOL.agent](https://github.com/openssh/openssh-portable/blob/master/PROTOCOL.agent) | Las extensiones de OpenSSH al protocolo del agente, entre ellas `session-bind@openssh.com`: el `bound agent to hostkey` de `ssh -v` |
| [OpenSSH — PROTOCOL.u2f](https://github.com/openssh/openssh-portable/blob/master/PROTOCOL.u2f) | Cómo son por dentro las llaves `-sk`: formato de la pública, el identificador del archivo privado y las opciones de toque y PIN |
| [OpenSSH (Wikibooks) — Public Key Authentication](https://en.wikibooks.org/wiki/OpenSSH/Cookbook/Public_Key_Authentication) | Capítulo libre con secciones sobre el agente, el forwarding y las llaves FIDO2. En inglés |
| [OpenSSH (Wikibooks) — Proxies and Jump Hosts](https://en.wikibooks.org/wiki/OpenSSH/Cookbook/Proxies_and_Jump_Hosts) | `ProxyJump`, la alternativa al agent forwarding para saltar entre servidores. Adelanto de la semana 09 |
