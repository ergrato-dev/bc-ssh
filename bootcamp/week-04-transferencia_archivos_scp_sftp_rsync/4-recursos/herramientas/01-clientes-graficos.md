## Multiplataforma

### FileZilla

- **URL**: https://filezilla-project.org
- **Plataformas**: Windows, macOS, Linux
- **Precio**: Gratuito (código abierto)
- **Características**:
  - Soporte SFTP, FTPS, FTP
  - Gestor de sitios
  - Transferencias en cola
  - Edición remota de archivos

```
Configurar conexión SFTP:
- Protocol: SFTP - SSH File Transfer Protocol
- Host: tu-servidor.com
- Port: 22
- Logon Type: Key file
- User: tu-usuario
- Key file: /ruta/a/tu/llave
```

### Cyberduck

- **URL**: https://cyberduck.io
- **Plataformas**: Windows, macOS
- **Precio**: Gratuito (donaciones)
- **Características**:
  - Interfaz limpia
  - Integración con editores externos
  - Sincronización
  - Soporte para múltiples protocolos

### WinSCP

- **URL**: https://winscp.net
- **Plataformas**: Windows
- **Precio**: Gratuito
- **Características**:
  - Interfaz Commander o Explorer
  - Scripting potente
  - Sincronización de directorios
  - Editor integrado
  - Integración con PuTTY

## Linux

### Nautilus (GNOME)

- **Incluido en**: GNOME Desktop
- **Cómo usar**:

```
1. Abrir Nautilus (Files)
2. Ctrl+L para barra de ubicación
3. Escribir: sftp://usuario@servidor/ruta
4. Conectar
```

### Dolphin (KDE)

- **Incluido en**: KDE Plasma
- **Cómo usar**:

```
1. Abrir Dolphin
2. En barra de ubicación: sftp://usuario@servidor
3. Guardar como marcador
```

### Thunar (XFCE)

- **Incluido en**: XFCE Desktop
- **Cómo usar**: Similar a Nautilus

### Double Commander

- **URL**: https://doublecmd.sourceforge.io
- **Estilo**: Gestor de archivos tipo Commander
- **Características**: Soporte SFTP integrado

## Clientes SSH con SFTP Integrado

### Termius

- **URL**: https://termius.com
- **Plataformas**: Todas (incluyendo móvil)
- **Precio**: Freemium
- **Características**:
  - Cliente SSH moderno
  - SFTP integrado
  - Sincronización entre dispositivos

### MobaXterm

- **URL**: https://mobaxterm.mobatek.net
- **Plataformas**: Windows
- **Precio**: Freemium
- **Características**:
  - Terminal SSH con panel SFTP automático
  - X11 forwarding

## Extensiones de Editor

### VS Code - SFTP

- **Extensión**: `Natizyskunk.sftp`
- **URL**: https://marketplace.visualstudio.com/items?itemName=Natizyskunk.sftp
- **Características**:
  - Sincronización automática
  - Upload al guardar
  - Comparación de archivos

### VS Code - Remote SSH

- **Extensión**: `ms-vscode-remote.remote-ssh`
- **Características**:
  - Editar archivos remotos directamente
  - Terminal integrada en servidor
