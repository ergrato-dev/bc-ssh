# Ebooks gratuitos — Semana 06

| Recurso | Descripción |
|---------|-------------|
| [OpenSSH (Wikibooks) — File Transfer with SFTP](https://en.wikibooks.org/wiki/OpenSSH/Cookbook/File_Transfer_with_SFTP) | `sftp` y `scp` paso a paso, lotes, y cómo encerrar usuarios de SFTP con `ChrootDirectory` (lo harás en la semana 07). En inglés |
| [The rsync algorithm (informe técnico)](https://rsync.samba.org/tech_report/) | El artículo original de Tridgell y Mackerras: sumas rápidas y fuertes, y por qué basta un recorrido. Base de la teoría 02. En inglés |
| [Efficient Algorithms for Sorting and Synchronization](https://www.samba.org/~tridge/phd_thesis.pdf) | Tesis doctoral de Andrew Tridgell; los capítulos sobre `rsync` desarrollan el algoritmo de diferencias. Nivel avanzado, en inglés |
| [SSH File Transfer Protocol (borrador IETF)](https://datatracker.ietf.org/doc/html/draft-ietf-secsh-filexfer-02) | La versión 3 del protocolo SFTP, la que implementa OpenSSH: qué operaciones existen y cómo viajan. Nivel avanzado |
