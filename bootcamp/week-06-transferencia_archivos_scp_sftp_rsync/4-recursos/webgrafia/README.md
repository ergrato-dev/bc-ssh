# Webgrafía — Semana 06

| Recurso | Descripción |
|---------|-------------|
| [scp(1)](https://man.openbsd.org/scp.1) | Todas las opciones de `scp`: `-3`, `-R`, `-O`, `-l`, `-P` |
| [sftp(1)](https://man.openbsd.org/sftp.1) | Órdenes de la sesión, lotes con `-b` y el prefijo `-` |
| [sftp-server(8)](https://man.openbsd.org/sftp-server.8) | El programa del servidor: `-R` (solo lectura) y `-d` (carpeta inicial) |
| [rsync(1)](https://download.samba.org/pub/rsync/rsync.1) | La referencia de `rsync`: `-a`, filtros, `--delete`, `--link-dest`, `--partial`, salida de `-i` |
| [rrsync(1)](https://download.samba.org/pub/rsync/rrsync.1) | `rrsync` en `authorized_keys`: `-ro`, `-wo` y qué opciones rechaza |
| [OpenSSH 9.0 — notas de la versión](https://www.openssh.com/txt/release-9.0) | El cambio de `scp` al protocolo SFTP por defecto, y por qué |
| [OpenSSH 8.7 — notas de la versión](https://www.openssh.com/txt/release-8.7) | Las copias entre dos remotos pasan por el equipo local por defecto |
| [ArchWiki — rsync](https://wiki.archlinux.org/title/Rsync) | Usos habituales, copias completas con `--link-dest` y un script de ejemplo |
| [rsnapshot](https://rsnapshot.org) | Herramienta de copias por niveles (diarias, semanales) construida sobre `rsync --link-dest` |
