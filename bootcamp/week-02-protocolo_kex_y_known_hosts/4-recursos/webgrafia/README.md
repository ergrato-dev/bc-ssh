# Webgrafía — Semana 02

| Recurso | Descripción |
|---------|-------------|
| [ssh_config(5)](https://man.openbsd.org/ssh_config) | Para esta semana: `KexAlgorithms`, `HostKeyAlgorithms`, `Ciphers`, `MACs`, `RekeyLimit`, `StrictHostKeyChecking`, `UpdateHostKeys`, `HashKnownHosts`, `HostKeyAlias` y `UserKnownHostsFile` |
| [sshd(8) — SSH_KNOWN_HOSTS FILE FORMAT](https://man.openbsd.org/sshd#SSH_KNOWN_HOSTS_FILE_FORMAT) | El formato oficial de `known_hosts`: patrones, puertos, hashes y marcadores |
| [ssh-keygen(1)](https://man.openbsd.org/ssh-keygen) | `-l`, `-E`, `-v`, `-F`, `-H` y `-R` |
| [ssh-keyscan(1)](https://man.openbsd.org/ssh-keyscan) | Opciones `-t`, `-p`, `-H` y `-T`, y su advertencia de seguridad |
| [OpenSSH — Post-quantum cryptography](https://www.openssh.com/pq.html) | Por qué OpenSSH usa intercambios híbridos y qué avisa desde la versión 10.1 si no se usan |
| [Terrapin Attack](https://terrapin-attack.com/) | Descripción del ataque, versiones afectadas y un escáner para comprobar servidores |
| [RFC 8308 — Extension Negotiation in SSH](https://www.rfc-editor.org/rfc/rfc8308) | `ext-info-c`/`ext-info-s` y el mensaje `EXT_INFO` |
| [RFC 4255 — SSHFP en DNS](https://www.rfc-editor.org/rfc/rfc4255) | Publicar huellas de host keys en DNS (`VerifyHostKeyDNS`) |
| [RFC 9142 — Key Exchange Method Updates](https://datatracker.ietf.org/doc/html/rfc9142) | Qué algoritmos de KEX se recomiendan y cuáles se retiran, como `group1-sha1` |
| [tcpdump(1)](https://www.tcpdump.org/manpages/tcpdump.1.html) | Las opciones `-i`, `-nn`, `-w`, `-r` y `-A` del lab-01 |
| [Wireshark — SSH](https://wiki.wireshark.org/SSH) | Cómo abrir una captura `.pcap` de SSH en Wireshark para ver los mismos mensajes con interfaz gráfica |
