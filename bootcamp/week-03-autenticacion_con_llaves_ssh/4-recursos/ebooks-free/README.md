# Ebooks gratuitos — Semana 03

| Recurso | Descripción |
|---------|-------------|
| [RFC 4252 — The Secure Shell (SSH) Authentication Protocol](https://www.rfc-editor.org/rfc/rfc4252) | La especificación de esta semana. Lee la sección 7 (método `publickey`): la pregunta sin firma, `PK_OK` y qué datos se firman |
| [RFC 8709 — Ed25519 and Ed448 Public Key Algorithms for SSH](https://www.rfc-editor.org/rfc/rfc8709) | Cómo se codifican en SSH las llaves y firmas Ed25519: el `AAAAC3NzaC1lZDI1NTE5` de tus `.pub` |
| [RFC 8032 — Edwards-Curve Digital Signature Algorithm (EdDSA)](https://www.rfc-editor.org/rfc/rfc8032) | El algoritmo de firma Ed25519. Basta con la introducción, que explica por qué no necesita un aleatorio al firmar. Nivel avanzado |
| [OpenSSH (Wikibooks) — Public Key Authentication](https://en.wikibooks.org/wiki/OpenSSH/Cookbook/Public_Key_Authentication) | Capítulo libre con generación, instalación, opciones de `authorized_keys` y diagnóstico de fallos. En inglés |
| [OpenSSH — PROTOCOL.key](https://github.com/openssh/openssh-portable/blob/master/PROTOCOL.key) | El formato `openssh-key-v1` campo a campo: lo que decodificaste en el lab 03 |
