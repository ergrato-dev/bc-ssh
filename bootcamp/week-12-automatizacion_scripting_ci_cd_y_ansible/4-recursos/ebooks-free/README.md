# Ebooks y documentos libres — Semana 12

| Recurso | Descripción |
|---------|-------------|
| [The Linux Command Line (William Shotts)](https://linuxcommand.org/tlcl.php) | Libro libre en PDF. Su parte 4, «Writing Shell Scripts», es la base de los labs 01 y 02: códigos de salida, `read`, bucles y comillas. En inglés |
| [BashGuide (Greg's Wiki)](https://mywiki.wooledge.org/BashGuide) | Guía de bash centrada en hacerlo bien: comillas, expansiones, `set -e` y sus trampas. En inglés |
| [OpenSSH Cookbook — Automated Backup (Wikibooks)](https://en.wikibooks.org/wiki/OpenSSH/Cookbook/Automated_Backup) | Llaves sin frase para tareas automáticas, limitadas con `command=` y `from=`: el lab 03 con otro ejemplo. En inglés |
| [Security hardening for GitHub Actions](https://docs.github.com/en/actions/security-for-github-actions/security-guides/security-hardening-for-github-actions) | Guía oficial: secretos, permisos del token, acciones de terceros y runners propios. El lab 04 y el workflow del proyecto. En inglés |
