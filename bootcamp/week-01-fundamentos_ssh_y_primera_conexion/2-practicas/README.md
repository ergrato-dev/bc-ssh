## 🎯 Objetivos

Al completar estas prácticas, serás capaz de:

- Instalar el cliente SSH en tu sistema operativo
- Conectarte a un servidor remoto con usuario/contraseña
- Crear y usar el archivo `~/.ssh/config`

---

## ⚠️ Prerequisitos

- Acceso a un servidor SSH (VPS, VM local, o contenedor)
- Terminal de línea de comandos
- Conexión a internet
