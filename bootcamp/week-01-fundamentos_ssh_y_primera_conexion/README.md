## 🎯 Objetivos de Aprendizaje

Al completar esta semana, serás capaz de:

- [ ] Explicar qué es SSH y por qué es superior a Telnet
- [ ] Describir la arquitectura cliente-servidor de SSH
- [ ] Comprender conceptos básicos de criptografía
- [ ] Instalar y configurar el cliente SSH
- [ ] Conectarte a servidores remotos con usuario/contraseña
- [ ] Crear el archivo `~/.ssh/config` básico
