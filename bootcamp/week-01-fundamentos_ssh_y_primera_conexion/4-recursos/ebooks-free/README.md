# Ebooks gratuitos — Semana 01

| Recurso | Descripción |
|---------|-------------|
| [OpenSSH (Wikibooks)](https://en.wikibooks.org/wiki/OpenSSH) | Libro libre y completo sobre OpenSSH. Para esta semana: capítulos *Overview*, *History* y *Client Configuration Files*. En inglés |
| [The Linux Command Line — William Shotts](https://linuxcommand.org/tlcl.php) | Libro libre (PDF) sobre la terminal. Si te falta base, el capítulo 16, *Networking*, presenta `ssh` y repasa redes. En inglés |
| [RFC 4251 — The Secure Shell (SSH) Protocol Architecture](https://www.rfc-editor.org/rfc/rfc4251) | El documento que define la arquitectura de SSH-2. Lee la sección 1 (introducción) y la 4.1 (host keys): explica el TOFU con las palabras originales |
