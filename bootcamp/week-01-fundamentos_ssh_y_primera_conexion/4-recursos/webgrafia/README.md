# Webgrafía — Semana 01

| Recurso | Descripción |
|---------|-------------|
| [ssh(1) — página de manual](https://man.openbsd.org/ssh) | Referencia del cliente. Para esta semana: DESCRIPTION, `-v`, `-p`, `-l`, `-t`, `-G` y la sección ESCAPE CHARACTERS |
| [ssh_config(5)](https://man.openbsd.org/ssh_config) | Formato de `~/.ssh/config`: el primer párrafo explica el orden de lectura y la regla de "gana el primer valor" |
| [sshd(8)](https://man.openbsd.org/sshd) | El servidor: cómo atiende cada conexión y qué archivos lee |
| [RFC 4253 — Transport Layer Protocol](https://www.rfc-editor.org/rfc/rfc4253) | Banners (sección 4.2) e intercambio de llaves (sección 7), las fases que lees con `ssh -v` |
| [OpenSSH — Historia del proyecto](https://www.openssh.com/history.html) | De dónde viene OpenSSH y por qué es la implementación de referencia |
| [OpenSSH — Notas de versión](https://www.openssh.com/releasenotes.html) | Qué cambia en cada versión. Útil para saber si una opción existe en 9.6 |
| [Ubuntu Server — OpenSSH server](https://documentation.ubuntu.com/server/how-to/security/openssh-server/) | Guía oficial de Ubuntu para instalar y configurar el servidor |
| [ArchWiki — OpenSSH](https://wiki.archlinux.org/title/OpenSSH) | Referencia práctica, muy completa, del cliente y el servidor |
| [DigitalOcean — Understanding the SSH Encryption and Connection Process](https://www.digitalocean.com/community/tutorials/understanding-the-ssh-encryption-and-connection-process) | Las fases de una conexión explicadas paso a paso, con la criptografía de cada una |
| [Docker Compose — Documentación](https://docs.docker.com/compose/) | Cómo funcionan `up`, `run`, `exec` y las redes que usa el laboratorio |
